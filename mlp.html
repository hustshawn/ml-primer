MLP · Multi-Layer Perceptron（在 Transformer 里也叫 FFN）

Transformer 的另一半

Transformer block 通常包含 attention 和 MLP。
在常见的 dense block 中，MLP 往往占约 2/3 的参数；一些研究也把它视为事实关联的重要干预位置。

扩展 → 非线性变换 → 压回
↓ 往下滑
01 · 它在哪

每个 block 里
都有它一份

Transformer 通常会重复堆叠同一种 block。一个标准 block 里有两个主要子层：

一层 attention，跟一层 MLP。再一层 attention，再一层 MLP……

这一半有很多名字：MLP、FFN（feed-forward network）、前馈层 —— 都是同一个东西。

02 · 分工

跨位置交互 vs
逐位置变换

attention 和 MLP 处理信息的范围不同：

Attention · 跨位置交互

每个 token 根据 attention 权重汇集其他位置的信息。「追」可以结合「猫」和「球」更新自己的表示。

MLP · 逐位置变换

每个 token 独立通过同一组 MLP 权重；MLP 本身不在 token 之间传递信息。

attention 混合不同位置的信息，MLP 对每个位置做非线性变换。

两者都会参与计算，但作用范围不同：attention 决定从哪些位置取信息，MLP 决定怎样变换当前 token 的表示。

03 · 长什么样

扩展、激活、压回

一个词进来是一个 d 维向量。MLP 对它只做三步：

输入和输出都是 d 维，中间表示扩展到 4d。

① 一个矩阵把向量从 d 维扩展到 4d；② 激活函数引入非线性；③ 另一个矩阵把结果压回 d 维，交给下一层。

这里没有循环状态，信号从输入直接流向输出，因此叫「前馈」（feed-forward）。

04 · 为什么需要非线性

没有激活函数，
多层仍等价于一层

假设去掉中间的激活函数，只剩两个矩阵：

W₂ ( W₁ x ) = ( W₂W₁ ) x = W x

两个矩阵乘在一起，还是一个矩阵。

连续的线性变换可以合并成一个线性变换。增加层数不会扩大这类网络能表示的函数范围。

加入激活函数后，前后两个矩阵不能再直接合并，网络才能表示非线性关系。下一节可以直接观察这个差别。

06 · 一个重要的细节

每个 token 独立处理，
共享同一组权重

MLP 是逐位置的：一段序列里有 1000 个 token，同一套权重就会在 1000 个位置上分别执行。不同位置不会在 MLP 内直接交换信息。

attention 让 token 使用其他位置的信息，MLP 再对每个位置的表示做非线性变换。一个 Transformer block 通常交替使用这两种操作。

堆叠多层后，位置之间的信息混合和逐位置变换会反复进行。

一条重要通路

输入模式被激活后，对应的内容会写回当前 token 的表示。

在一些模型和事实回忆任务中，中间层 MLP 是重要的干预位置。ROME 也通过修改 MLP 权重来编辑特定事实关联。这说明 MLP 很重要，不等于模型的大部分知识只存在这里。

08 · 掂掂分量

常见 dense block 中，
MLP 参数通常约占 2/3

算一层 block 的参数账（隐藏维度 d）：attention 四个矩阵共约 4d²，MLP 两个大矩阵共约 8d²。

Attention · 4d²
MLP · 8d²

以常见结构为例：MLP 参数约占一层 block 的 2/3。

因此在标准 dense Transformer 中，MLP 通常是参数和计算量的主要来源。MoE 等设计也经常从这一部分入手。

09 · 它的现在

激活函数会变，
MoE 会引入多个 MLP 专家

激活函数不断变化，但扩展、激活、压回的基本结构仍然常见：

ReLU · 2017 原版 → GELU · GPT-2 / BERT → SwiGLU · LLaMA / Qwen / Mistral

SwiGLU 用三个矩阵（多一路「门」），为了参数量持平，中间宽度从 4d 降到约 8d/3 —— 总账不变，还是 ≈ 8d²。

MoE 里的「专家」，就是一堆 MLP。

把一个大 MLP 换成很多个，每个 token 只挑几个走（如 Mixtral：每层 8 个专家，走 2 个）。

MoE 通常把 MLP 换成多个专家，因为 MLP 是 dense block 中参数和计算量的主要来源。每个 token 只激活少数专家，可以增加总参数量而不同比例增加计算量。

class MLP(nn.Module):
    def __init__(self, d):
        self.up   = nn.Linear(d, 4*d)   # ① 扩展
        self.act  = nn.GELU()            # ② 非线性激活
        self.down = nn.Linear(4*d, d)   # ③ 压回

    def forward(self, x):    # x: [batch, seq, d]
        return self.down(self.act(self.up(x)))
        # 只作用在最后一维 —— 每个 token 独立过，天然并行

attention 混合不同位置的信息，
MLP 对每个位置做非线性变换。
