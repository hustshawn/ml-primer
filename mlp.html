MLP · Multi-Layer Perceptron（在 Transformer 里也叫 FFN）

被冷落的另一半

所有人都在讲 attention。
但每个 Transformer block 里还有另一半 —— MLP，
在标准 dense block 里，它约占 2/3 的参数，也参与存取事实关联。

摊开 → 掰弯 → 压回
↓ 往下滑
01 · 它在哪

每个 block 里
都有它一份

Transformer 就是同一种 block 摞几十层。掰开任何一个 block，里面只有两个零件，永远成对出现：

一层 attention，跟一层 MLP。再一层 attention，再一层 MLP……

这一半有很多名字：MLP、FFN（feed-forward network）、前馈层 —— 都是同一个东西。

02 · 分工

开会 vs 各自消化

这两个零件干的是完全不同的两件事：

Attention · 开会

词与词之间搬信息。「追」看一眼「猫」和「球」，把有用的搬到自己身上。

MLP · 各自消化

每个词独立加工刚搬来的信息。注意：词和词之间一根线都没有。

attention 负责通信，MLP 负责计算。

attention 干完的活只是「把该看的东西加权平均到眼前」—— 信息还是原来那些信息，只是换了个位置。真正把它们加工成新东西的，是 MLP。

03 · 长什么样

摊开、掰弯、压回

一个词进来是一个 d 维向量。MLP 对它只做三步：

进来 d 维，出去还是 d 维 —— 但中间摊开成 4d，给「想事情」留足桌面。

① 一个大矩阵把向量放大 4 倍；② 过一个激活函数，把负数压掉、把直线掰弯；③ 另一个大矩阵压回原来的尺寸，好交给下一层。

就这么多。没有循环、没有分支 —— 所以叫「前馈」（feed-forward）。

04 · 为什么非要「掰弯」

不掰弯，
一百层等于一层

假设把中间那步 ⚡ 拿掉，只剩两个矩阵。数学上会发生一件尴尬的事：

W₂ ( W₁ x ) = ( W₂W₁ ) x = W x

两个矩阵乘在一起，还是一个矩阵。

连乘多少个矩阵，结果都能合并成一个矩阵——摞一百层跟一层没区别，画来画去只能画直线。

中间插一个激活函数，合并就失效了。非线性是整个网络能「学出复杂东西」的前提。下一节你可以亲手感受这件事。

05 · 亲手试试

神经元 = 折点

这是一个最小号的 MLP：进 1 个数、出 1 个数，中间摊开成 N 个神经元 —— 跟上面 d → 4d → d 是同一个形状。让它去描一条曲线：

→ →
平均偏差 –

每个神经元贡献一个折点。神经元越多，折线越贴近曲线 —— 加到够多，什么形状都描得出来（这就是「万能近似定理」说的事）。

把激活函数关掉再拖拖看：不管多少个神经元，永远是一条直线。

06 · 一个重要的细节

每个词各自过，
用的是同一台机器

MLP 是逐位置的：一句话里有 1000 个词，就是同一套权重被独立地跑 1000 遍。词和词在这里互相看不见。

所以这两个零件缺一不可：MLP 再能算，自己看不见邻居 —— 得靠 attention 先把上下文搬过来；attention 再能搬，自己不会深加工 —— 得靠 MLP 把搬来的信息变成新的判断。

一层 block = 开一次会 + 各自消化一次。摞几十层，就是反复开会、反复消化。

07 · 它还是仓库

MLP 是事实记忆的
一条重要通路

有研究把 MLP 的两个大矩阵解释成一柜子抽屉：

上下文对上某个模式 → 对应抽屉打开 → 内容被加进这个词的向量里。

在一些模型和事实回忆任务中，中间层 MLP 是重要的干预位置。ROME 也通过修改 MLP 权重来编辑特定事实关联。这说明 MLP 很重要，不等于模型的大部分知识只存在这里。

出处：Transformer Feed-Forward Layers Are Key-Value Memories，Geva et al.，EMNLP 2021；Locating and Editing Factual Associations in GPT，Meng et al.，2022。

08 · 掂掂分量

2/3 的体重在这里

算一层 block 的参数账（隐藏维度 d）：attention 四个矩阵共约 4d²，MLP 两个大矩阵共约 8d²。

Attention · 4d²
MLP · 8d²

一层 block 的参数分布 —— MLP 拿走约 2/3。

所以你下载的那几十 GB 权重，大部分是 MLP。也因此，所有想省参数、省算力的招，都先打它的主意 ——

09 · 它的现在

换了激活，
裂成了专家

「掰弯」的手法一直在换，骨架从没变过：

ReLU · 2017 原版 → GELU · GPT-2 / BERT → SwiGLU · LLaMA / Qwen / Mistral

SwiGLU 用三个矩阵（多一路「门」），为了参数量持平，中间宽度从 4d 降到约 8d/3 —— 总账不变，还是 ≈ 8d²。

MoE 里的「专家」，就是一堆 MLP。

把一个大 MLP 换成很多个，每个 token 只挑几个走（如 Mixtral：每层 8 个专家，走 2 个）。

为什么 MoE 偏偏拆 MLP、不拆 attention？因为上一节刚算过 —— 它是参数和算力的大头，拆它最划算。

10 · 全部内容

几行写完

class MLP(nn.Module):
    def __init__(self, d):
        self.up   = nn.Linear(d, 4*d)   # ① 摊开
        self.act  = nn.GELU()            # ② 掰弯
        self.down = nn.Linear(4*d, d)   # ③ 压回

    def forward(self, x):    # x: [batch, seq, d]
        return self.down(self.act(self.up(x)))
        # 只作用在最后一维 —— 每个 token 独立过，天然并行

一句话：
attention 把信息搬到眼前，
MLP 把信息消化成新的。
模型的知识和体重，大半都在这另一半里。
