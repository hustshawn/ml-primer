非线性 / NONLINEARITY

线性只会按比例
非线性会看情况

「非线性让网络能学复杂的东西」—— 这句话你已经听过了。
这一页不讲它有什么用，只讲为什么。

三十秒版

线性的全部本事：给每个输入乘一个固定的数，然后加起来。就这样。

于是它有三个绕不过去的毛病：

  1. 叠一百层，还是等于一层
  2. 永远只能「一刀切」
  3. 不会看情况 —— 它在任何地方都用同一个规则

往中间塞一个最小号的 if（比如 max(0, x)），这三条同时解除。
这就是非线性。

01 · 先把「线性」这个词讲清楚

线性不是「看起来是直线」，
是两条可以当场验的规矩

大部分人对线性的印象是「画出来是直的」。这个印象没错，但它是结果，不是定义。定义是这两条：

1输入翻倍，输出就翻倍。翻三倍就翻三倍，减半就减半。
2分开算再加起来，等于合起来算。两个人的行李分别称重再相加，和放一起称，一样重。

这两条同时满足 = 线性。少满足一条 = 非线性。真的就这么简单，没有别的门槛。

下面是一个每个月都会出现在你生活里的对比。左边那种收费满足这两条，右边那种不满足：

实验台 A · 翻倍检验

阶梯价这里用的是示意数字（0.5 元/度，超过 200 度的部分 0.8 元）；真实档位各地不同。

注意右边那条线的形状：两段直线，中间一个折点。它已经是非线性了 —— 非线性不需要是什么优美的曲线，一个折点就够。

顺手记住这个形状，因为 ReLU 长得跟它一模一样。你在阶梯电费单上见过的东西，就是神经网络里最常用的那个非线性。

02 · 世界本来就不成比例

线性是特例，
非线性才是常态

我们先学线性，只是因为它好算。但真实世界里「翻倍就翻倍」几乎不成立：

阈值
99°C → 100°C

前面每一度都只是「更热一点」。最后这一度，水直接换了形态。同样多的输入，效果完全不同。

饱和 / 反转
1 杯咖啡 → 6 杯

第一杯让你清醒。第六杯不会让你清醒六倍，它让你手抖。效果不但不成比例，还会反向。

相互作用
盐好吃，糖好吃

各自加一点都好吃。同时猛加两样，难吃。1 + 1 在这里等于 0 —— 第 2 条规矩直接破了。

最后那个例子最要紧，先把它记住：「A 单独出现好，B 单独出现好，A 和 B 一起出现反而糟」—— 这种事线性永远表达不了。

因为线性只会给 A 打一个固定的分、给 B 打一个固定的分，然后相加。既然两个分都是正的，加起来必然更高。它在结构上就没有地方安放「一起出现时反而糟」这句话。第 5 节你会亲手撞上这堵墙。

03 · 软肋到底在哪

线性不会
「看情况」

把线性的毛病压缩成一句话，就是这句。展开讲：

线性函数的斜率处处相同。在 x = 0 附近多给一个单位，和在 x = 1000 附近多给一个单位，效果一模一样。它不知道自己现在身处何地。

而「看情况」是一切有意思的判断的核心：

  • 情况下第 1 勺盐 vs 下第 20 勺盐 —— 同一个动作，一次是改善，一次是毁掉
  • 情况「便宜」对买菜是好话，对手术刀是坏话 —— 同一个词，符号相反
  • 情况只有当「河」出现过，「bank」才是河岸 —— B 重不重要，取决于 A 在不在

这些句子都有一个共同的骨架：如果……那么……否则……。而线性层里没有 if，一个都没有 —— 它只有乘法和加法。

ReLU 就是把 if 补进去的最小零件。它常被写成 max(0, x)，但更该这样读：

# ReLU 的真身：一个 if，两个分支
def relu(x):
    if x > 0:
        return x        # 情况一：原样放过
    else:
        return 0        # 情况二：关掉

就是这么个东西。一个神经元 = 一个 if。一层里有几千个神经元，就是几千个「如果……」同时在判断当前输入落在哪种情况里；层与层叠起来，就是「如果……的话，再看是不是……」。

你熟悉的程序之所以能干活，靠的就是 if 和分支。线性网络是一个没有 if 的程序 —— 它只能算一个加权总分。非线性做的事，是把 if 还给它。

04 · 「一百层等于一层」的看图版

线性变换只会做
四件事

你已经见过代数版的解释：W₂(W₁x) = (W₂W₁)x = Wx，两个矩阵乘起来还是一个矩阵。它是对的，但它没告诉你这在形状上意味着什么。所以换个看法。

把输入空间想成一张方格纸。一个线性层能对这张纸做的，只有四件事：拉、压、转、翻。做完之后，纸有四个性质是雷打不动的：

性质 1
直线还是直线

纸上任何一条直线，变换后仍然是直线。永远不会弯。

性质 2
平行还是平行

原来平行的两条线，之后仍然平行、仍然等距。

性质 3
原点不动

零进去，零出来。

性质 4
格子处处一样

整张纸被同一个规则均匀地拉伸，没有哪个角落是特殊的。

第 4 条就是「不会看情况」的几何版。变换之后的空间，每个角落长得都一样 —— 你没办法让左上角遵守一套规则、右下角遵守另一套。

（真实的线性层还带一个 bias，Wx + b，严格说该叫「仿射」。它只影响第 3 条 —— 原点会被挪走。第 1、2、4 条一字不变，所以该合并的照样合并：W₂(W₁x + b₁) + b₂ = W₂W₁x + 常数。加不加 bias，都画不出弯的东西。）

自己拨一下。前两个按钮是纯线性的，第三个在中间插了一次 ReLU：

实验台 B · 方格纸

对比第二个和第三个按钮：过两个线性层的结果，跟直接过一个矩阵完全一样 —— 格子还是笔直、平行、均匀。这就是「一百层等于一层」在图上的样子：你反复拉压转翻一张方格纸，得到的还是一张方格纸。

而加了 ⚡ 之后，图上出现了两件线性变换永远做不到的事：

1出现了折痕。纸不再处处一样了 —— 折痕两侧是两套不同的规则。空间从此有了「地形」，而有地形才谈得上「看情况」。
2有区域被压平了，整整一块被压成了一个点。这意味着不同的输入可以走向同一个结果 —— 信息被主动丢掉了。线性变换（除了退化情况）是可逆的，它舍不得扔任何东西；而「忽略无关的部分」恰恰是一切识别、归类、抽象的前提。
05 · 亲手撞一次墙

盐和糖：
一刀切不开的题

回到第 2 节那道菜。把它画成一张图：横轴是加不加盐，纵轴是加不加糖。

  • 蓝都不加 → 能吃；两样都猛加 → 难吃到另一个极端。（这两堆算同一类：「口味失衡」）
  • 红只加盐 → 好吃；只加糖 → 好吃。（这两堆是另一类：「好吃」）

好吃的两堆在对角线上。现在请你用一条直线，把红的和蓝的分开。

下面这台机器有两个可调的「刀」，⚡ 开关控制刀切完之后要不要先各自过一次 ReLU。先别开 ⚡，随便怎么拖，看能到多少分：

实验台 C · 两把刀

关 ⚡ 时，天花板是 75%。不是你没拖到位 —— 是拖不到。四堆点里必然有一堆站在错误的一侧。

关键在于为什么明明有两把刀，却只切出了一刀：

(s − b₁) − 2(s − b₂) = −s + 常数

两把刀的分数直接相加，合并成了一把刀。

这就是 W₂W₁ = W 在这张图上的长相。不是刀不够多，是没有 ReLU 时，刀会自动互相合并。你加再多把刀、堆再多层，它们全都塌成同一条直线。

现在打开 ⚡。同样两把刀、同样的位置滑块，只多了一次 max(0, ·)：100%。

为什么这次没合并？因为 ReLU 把每把刀「不该管的那半边」按平成了 0。第一把刀只在自己右边有话说，第二把刀只在自己右边有话说 —— 两个人管的地盘不再完全重合，相加就不会互相抵消了。于是两把刀真的成了两把，夹出一条带，把中间那类圈了出来。

「用一条带把中间圈出来」这件事，一条直线做不到；两条直线只要能各管一段，就做到了。ReLU 提供的就是「各管一段」。

06 · 深度为什么划算

ReLU 干的事，
其实是折纸

到这里「为什么需要非线性」已经答完了。但还有半个问题：为什么要很多层非线性？

小时候玩过的那个手工就是答案：一张纸对折几次，剪一刀，展开来是一排口子。

实验台 D · 折纸

每加一层，纸就多对折一次，之前所有的折痕跟着翻一倍。这就是为什么深比宽划算：

摊成一层
加法

N 个神经元最多给你 N+1 段。想要更细的形状，只能一个一个往里塞。

摞成深层
乘法

每层 2 个神经元、共 n 层，能折出 2n 段。层数进指数。

这不是比喻，是有严格构造的：Montúfar 等人 2014 年数过 ReLU 网络能切出的线性区域数量，Telgarsky 2016 年用的正是这个反复折叠的锯齿函数，证明浅网络要达到同样的表达力，宽度必须指数级增长。前提仍然是那个 ⚡ —— 没有它，折不起来，一百层还是一层。

07 · 回到语言

语言里几乎
全是「看情况」

假设有个只会线性的模型来判断一句话是好评还是差评。它能做的事只有一件：给每个词一个固定的分，加起来，看总分过不过线。

「这电影不好看」

线性模型：「好看」+3，「不」−1，总分 +2 → 判成好评。

但「不」做的事不是减一点分，是把后面整句翻过来。翻转是乘 −1，而乘多少取决于后面跟着什么 —— 这是输入和输入相乘，线性做不到（线性只允许输入乘固定的权重）。

  • 看情况「他这演技真是绝了」—— 褒还是贬，取决于上文。同样的词，相反的分。
  • 看情况「苹果」是水果还是公司，看旁边有没有「股价」。
  • 看情况「你行你上」—— 逐词打分算出来的意思，和整句的意思毫无关系。

一个只会「每个词打固定分再相加」的模型，天花板就是词袋模型：它知道句子里出现了哪些词，永远不知道这些词凑在一起是什么意思。而语言的意思几乎全在「凑在一起」里。

所以非线性对语言模型不是一个可选的性能优化，是入场券。

08 · 都藏在哪

Transformer 里的
非线性清单

常见的误解是「非线性只在激活函数里」。其实一个 block 里有好几处，也有好几处是纯线性的 —— 分清楚它们，很多设计上的选择就顺了：

  • 非线性MLP 里的激活（ReLU / GELU / SwiGLU）—— 最标准、最显眼的那一个。
  • 非线性attention 权重。它算的是 Q 和 K 的乘积 —— 输入乘输入，不是输入乘固定权重。再过一次 softmax（带指数和除法）。attention 之所以强，很大一部分就是这个「谁重要由内容当场决定」的非线性。
  • 非线性归一化（LayerNorm / RMSNorm）。除以的是输入自己算出来的均方根 —— 输入翻倍，输出不变。第 1 条规矩当场就破了。
  • 线性残差的那个加号。它解决的是信号能不能传到深层，跟表达能力无关 —— 别把它算成非线性来源。
  • 线性Q / K / V 投影、MLP 的两个大矩阵、最后的输出层。这些都是矩阵乘法，本身一点非线性都不提供。

顺着这份清单看第 4 节那句话就更清楚了：模型里绝大部分参数在做线性的事，非线性只负责在中间插入「折痕」。分量很小，但去掉它，剩下那几千亿参数会一起塌成一个矩阵。

09 · 三个常见误解

非线性 ≠ 复杂

误解一：非线性意味着复杂的公式

max(0, x) 比乘法还简单：两段直线拼一下，一个分支判断。它是整个深度学习里最廉价的零件之一，却是那个不可或缺的。

误解二：非线性就是「弯曲」

ReLU 身上一处弯都没有，全是直的。真正起作用的是分段 —— 不同区域用不同规则。至于最后画出来的曲线，是几千个折点拼出来的效果，不是单个函数自己弯的。

误解三：那用 x² 或 sin 岂不是更「非线性」

「非线性程度」不是越高越好，能不能训得动才是。x² 的输出随输入平方增长，几十层叠下来数值直接爆掉；sin 到处周期振荡，同一个输出对应无数个输入，优化器无从下手。

实用的激活函数几乎都长成同一副样子：负的关掉（或者压小），正的原样放过 —— 一个门。GELU、SiLU、SwiGLU 都能写成 x × 一个 0~1 的门。要的从来不是「弯」，是开关。

10 · 一句话

线性只会按固定比例打分、相加；
非线性让它学会说「看情况」。

再回头看 MLP 那三步 —— 摊开、掰弯、压回。摊开和压回是两个矩阵，它们负责提供参数和容量；中间那一下「掰弯」不提供任何容量，它只做一件事：让前后两个矩阵没法合并。

没有它，那两个矩阵就是同一个矩阵，一百层就是一层，几千亿参数只够画一条直线。
