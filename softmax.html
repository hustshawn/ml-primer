1

只有三步

整个 softmax 就这三步。没有第四步。

STEP 1

全变正数

e分数

每个分数都放到 e 的头上。
负数也变正，而且大的被拉得更大。

STEP 2

加起来

Σ

把上一步的结果全部加总，
得到一个「总量」。

STEP 3

各自除以总量

÷ Σ

每个都变成「占总量的几分之几」。
加起来必然是 1。

用刚才那四个数字走一遍
候选词① 原始分数② 放到 e 头上③ 除以总量
好2.07.3964%
热1.02.7223%
冷0.11.1110%
香蕉−1.00.373%
总量（加起来 2.1，没意义）11.58100%

第三列除以 11.58，就是第四列。就这样，结束了。

2

为什么非得套个 e？

直接「每个除以总和」不行吗？不行 —— 三个理由。

理由一

负数会出事

−1.0 直接除，得出「−48% 的概率」。
e 的头上永远是正数，问题消失。

理由二

该拉开差距

分数差 1 分，概率差不该只有一点点。
e 让领先者拿走更大份额，同时垫底的不会被清零。

理由三 · 真正的原因

求导特别好看

和训练用的 loss 配在一起，梯度化简成一句话：
预测 − 正确答案
训练时最省事的形式，就长这样。

你在 API 里调的 temperature，就是在 softmax 之前把所有分数除以 T。拖一下试试。

原始分数原封不动进 softmax。

T 小 → 拉大差距

强者更强，弱者归零。
越来越像「赢家通吃」。
T→0 就是永远选第一名。

T = 1 → 不动

除以 1，等于什么都没做。
模型原本的判断。

T 大 → 压平差距

大家越来越接近。
「香蕉」也开始有机会。
数学上 T→∞ 就是纯抽签。

注意：温度不改变谁是第一名，只改变第一名领先多少。所以它调的是「敢不敢冒险」，不是「聪不聪明」。

容易被误会的一点：T 在数学上可以无限大，但产品里不行
在哪调实际允许的范围依据
Claude
（Anthropic）		 0.0 – 1.0 官方 SDK 里写明「默认 1.0，范围 0.0 到 1.0」。而 Opus 4.6 之后的新模型已经不支持设置了 —— 只接受 1.0，填别的值直接报 400，这个参数在新版 Python SDK 里被整个删掉了。
OpenAI 0.0 – 2.0 官方 OpenAPI 规范：minimum: 0 / maximum: 2 / default: 1。
自己跑模型
（vLLM / transformers）		 任意正数 源码里就是个 float，默认 1.0，没有上限检查。想试 T = 50 只能在这里试。

所以「T 可以无限大」是公式的性质，不是你在 API 里的可调范围。而且超过 1 之后输出质量掉得很快 —— 这就是为什么绝大多数场合，这个值实际就在 0 ~ 1 之间。

还有一个小坑：T = 0 也不保证每次结果一模一样。Anthropic 文档明确写了「即便 temperature 为 0.0，结果也不会完全确定」—— 因为浮点计算和批处理本身就带抖动，跟 softmax 无关。

5

在大模型里，它出现在两个地方

很多人只知道第一个。第二个其实更关键。

① 出口：挑下一个词

模型对词表里十几万个词各给一个分数 → softmax → 变成概率 → 抽一个出来。这就是你调 temperature 影响的那个。

12万个分数→SOFTMAX→12万个概率，和为1→采样出一个词

② 内部：注意力决定「看哪里」

每读一个词，模型给前文每个词打一个「相关度」分 → softmax → 变成一组和为 1 的权重 → 按权重把前文混合起来。
Attention 的那个「注意力分配」，本体就是一次 softmax。一个模型跑一遍，这里要做几十万次。

它和每个前文词的相关度→SOFTMAX→注意力权重，和为1→加权取信息
6

两个值得知道的细节

工程

整体减一个数，结果不变

e1000 会把计算机撑爆。
解决办法出乎意料地简单：所有分数一起减去最大值，再算 softmax。

[2.0, 1.0, 0.1, −1.0]
↓ 全部 −2.0
[0, −1.0, −1.9, −3.0]
→ 概率一模一样：64% / 23% / 10% / 3%

softmax 只在乎分数之间差多少，不在乎绝对值。所以每个真实实现里都有这一行。

易误解

「99%」不等于「99% 是对的」

softmax 是把分数规范化，不是做民意调查。它保证「加起来等于 1」，不保证这个数字对应真实世界的可信度。

模型可以 99% 的把握，答一个错的。

因为分数是训练出来的，softmax 只是忠实地把它们摊成百分比。垃圾进，规范化的垃圾出。

这件事有个专门名字叫校准（calibration），是一个独立的研究问题。

记三句就够

1 · softmax = 套个 e，再各自除以总和。目的只有一个：让一堆乱数变成加起来是 1 的概率。

2 · 为什么要「软」？因为硬着来（只留第一名）没有梯度，模型就没法训练。

3 · temperature 就是进 softmax 前先除以 T。它只改变第一名领先多少，不改变谁是第一名。
