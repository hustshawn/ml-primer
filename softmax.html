1

只有三步

整个 softmax 就这三步。没有第四步。

STEP 1

全变正数

e分数

每个分数都放到 e 的头上。
负数也变正，而且大的被拉得更大。

STEP 2

加起来

Σ

把上一步的结果全部加总，
得到一个「总量」。

STEP 3

各自除以总量

÷ Σ

每个都变成「占总量的几分之几」。
加起来必然是 1。

用刚才那四个数字走一遍
候选词① 原始分数② 放到 e 头上③ 除以总量
好2.07.3964%
热1.02.7223%
冷0.11.1110%
香蕉−1.00.373%
总量（加起来 2.1，没意义）11.58100%

第三列除以 11.58，就是第四列。就这样，结束了。

2

为什么非得套个 e？

直接「每个除以总和」不行吗？不行 —— 三个理由。

理由一

负数会出事

−1.0 直接除，得出「−48% 的概率」。
e 的头上永远是正数，问题消失。

理由二

该拉开差距

指数会把分数差变成比例差。
高分项获得更大权重，低分项仍保持正值。

理由三 · 和训练目标配合

求导特别好看

和训练用的 loss 配在一起，梯度化简成一句话：
预测 − 正确答案
训练时最省事的形式，就长这样。

原始分数原封不动进 softmax。

T 小 → 拉大差距

强者更强，弱者归零。
越来越像「赢家通吃」。
最高分唯一时，T→0 会集中到第一名。

T = 1 → 不动

除以 1，等于什么都没做。
模型原本的判断。

T 大 → 压平差距

大家越来越接近。
「香蕉」也开始有机会。
数学上 T→∞ 就是纯抽签。

温度不改变 logits 的排序，只改变分布的集中程度。温度调的是采样分布，不会直接提高模型能力。

各家 API 支持的 temperature 范围
在哪调实际允许的范围依据
Claude
（Anthropic）		 视模型而定 支持自定义温度的 Claude 模型通常接受 0.0–1.0。从 Opus 4.7 起，部分新模型只接受默认值 1.0；参数仍存在于通用 API / SDK 类型中，是否可调由具体模型决定。
OpenAI 通常 0.0 – 2.0 许多生成模型接受 0–2，但部分推理模型不支持这个参数。调用时应以具体模型文档为准；还可以使用 top_p 等采样参数。
自己跑模型
（vLLM / transformers）		 任意正数 源码里就是个 float，默认 1.0，没有上限检查。想试 T = 50 只能在这里试。

「T 可以无限大」是公式的性质，不代表每个 API 都开放相同范围。产品还可能提供 top_p、top_k 等采样参数。T = 0 也不保证每次结果完全一致；Anthropic 文档明确说明了这一点，浮点计算和批处理都可能影响最终结果。

5

在大模型里，它出现在两个地方

一个在模型输出端，另一个在每层 attention 内部。

① 出口：挑下一个词

模型对词表里十几万个词各给一个分数 → softmax → 变成概率 → 抽一个出来。这就是你调 temperature 影响的那个。

12万个分数→SOFTMAX→12万个概率，和为1→采样出一个词

② 内部：注意力决定「看哪里」

每读一个词，模型给前文每个词计算一个相关度分数 → softmax → 变成一组和为 1 的权重 → 按权重混合前文信息。
Attention 的权重计算中包含一次 softmax，并且会在各层、各个 head 和各个位置重复执行。

它和每个前文词的相关度→SOFTMAX→注意力权重，和为1→加权取信息
6

两个值得知道的细节

工程

整体减一个数，结果不变

e1000 会把计算机撑爆。
解决办法出乎意料地简单：所有分数一起减去最大值，再算 softmax。

[2.0, 1.0, 0.1, −1.0]
↓ 全部 −2.0
[0, −1.0, −1.9, −3.0]
→ 概率一模一样：64% / 23% / 10% / 3%

softmax 只在乎分数之间差多少，不在乎绝对值。所以每个真实实现里都有这一行。

易误解

「99%」不等于「99% 是对的」

softmax 是把分数规范化，不是做民意调查。它保证「加起来等于 1」，不保证这个数字对应真实世界的可信度。

模型可以 99% 的把握，答一个错的。

因为分数是训练出来的，softmax 只是忠实地把它们摊成百分比。垃圾进，规范化的垃圾出。

这件事有个专门名字叫校准（calibration），是一个独立的研究问题。

记三句就够

1 · softmax = 套个 e，再各自除以总和。目的只有一个：让一堆乱数变成加起来是 1 的概率。

2 · softmax 连续可导，可以直接配合梯度法训练；argmax 不能直接用于标准反向传播。

3 · temperature 就是进 softmax 前先除以 T。它只改变第一名领先多少，不改变谁是第一名。
