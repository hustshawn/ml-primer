残差连接 · RESIDUAL

保留主干，
逐层增加改动

普通层会用新输出替换输入；残差连接保留输入主干，
让每一层只需要学习一个增量。

没有残差 原话 x → 这一层 → 全新的话，原话没了
有残差 原话 x → 这一层 → 原话 + 便签
out = x + f(x)

核心就是一个加号。它不增加可训练参数，加法本身的计算开销也很小。

1

没有残差时，层层替换输入

神经网络是一层传给下一层。层数一多，每层都想「改写」上一层的话，改到最后就是耳语传话——面目全非。

没有残差：每层重写

输入小明昨天在北京买了一辆红色的车
↓ 第 1 层重写
小明昨天在北京买了红车
↓ 第 2 层重写
小明买了红车
↓ 第 3 层重写
有人买了车
↓ 第 4 层重写
买东西
↓ 第 5 层重写
……？
原话已经找不回来了

有残差：原话不动，只加便签

小明昨天在北京买了一辆红色的车
↑ 这一行从头到尾都在
层1 +「小明」是人名
层2 +「北京」是地点
层3 +「红色」修饰的是车
层4 +「买」= 交易动作，过去时
层5 +整句是陈述、已完成
最后读到的 = 原话 + 全部便签
残差连接不会跳过这一层的计算

每一层仍然会计算，只是它的输出被 加 回主干，而不是用来替换主干。
这一层学习的是相对于输入的增量，也就是名称中的「残差 / residual」：差值。

前 3 节先把「层」当成一个黑盒。它可以是卷积、attention 或其他算子，残差连接只关心输出怎样并回主干。第 4 节会展开 Transformer 里的具体结构。

2

反向传播：连乘会让梯度衰减

训练时，梯度从最后一层向前传播。每经过一层，梯度都会乘上该层的局部导数；连续相乘很多次后，数值可能变得很小。

96
没有残差 —
有残差 100%

没有残差

0.8 × 0.8 × 0.8 × … （96 次）

= 0.00000005%
信号到不了底层。底层的参数几乎不更新，等于白搭了 90 层。这叫梯度消失。

乘数稍大于 1 也一样糟：1.196 ≈ 8600，直接炸成 NaN

有残差

d(x + f(x)) / dx = 1 + f′(x)

那个 1 是一条直通电梯：
1 × 1 × 1 × … = 1
不管多少层，永远有一条不衰减的路把信号送到底。

这才是「能训 100 层」的原因
3

残差让新增层更容易退化为恒等映射

2015 年的 ResNet 论文观察到：56 层网络的训练误差比 20 层网络更高。训练集本身都没有拟合好，因此问题不在过拟合，而在深层网络更难优化。

要一层「什么都别做」

没有残差：它得学会照抄——把输入一字不差地复现出来。看着简单，对一堆随机初始化的矩阵来说非常难。

类比：让编辑「原文抄一遍，不许出错」

有残差：只要不写字

out = x + f(x)，想不做事只需 f(x) → 0。把权重压到 0 是优化器最容易做到的事之一。

类比：让编辑「这页不用改，空着」
新增层可以学成接近恒等映射

多出来的层如果暂时没有帮助，可以让 f(x) 接近 0，从而尽量保留原输入。这让深层网络更容易优化。
ResNet 借此把图像网络扩展到 152 层，Transformer 也采用了同样的连接方式。

4

残差连接和 Attention 属于不同层面

残差连接决定子层输出怎样接回主干，Attention 则是一个具体的计算子层。

残差连接 = 输出怎样接回主干

子层计算完成后，把结果加回主干。
这种连接方式不限定子层内部使用哪种算子。

0 个参数

Attention = 具体计算子层

它负责计算一个 token 应该参考序列中的哪些 token。
同一个 Attention 算子可以采用不同的连接方式。

一大堆参数
而且「一层」里不止一个东西

口语里的「一层」= 一个 Transformer block = 两个子层，两个残差加号：

x = x + Attention(norm(x))   ← 子层 1：去别人那儿看看
x = x + FFN(norm(x))         ← 子层 2：自己再想想

所以 GPT-3 的「96 层」= 96 个 block = 192 个残差加号。
Attention 只是这两个子层里的一半。

Attention 子层

干什么跨 token 看别人
看得到别的词吗能，负责 token 之间的信息传递
白板比喻抄一眼旁边人的白板，再写便签
参数量约 1/3（4d²）

FFN 子层

干什么每个 token 自己想
看得到别的词吗看不到，逐位置独立处理
白板比喻只看自己白板，加工一下再写便签
参数量约 2/3（8d²）

Norm 也是逐 token 的（它在特征维度上归一化，不跨词）。因此在标准 Transformer block 中，token 之间的信息由 attention 子层传递。

替换子层即可看出两者相互独立

ResNet 的子层是卷积，Mamba 的子层是 SSM，它们都可以保留同样的残差连接。
Mamba 不使用 attention，但仍然使用残差连接。

反过来，attention 在没有残差连接时仍能完成计算，只是深层网络会更难训练（第 2 节）。
因此，子层类型和残差连接是两个可以独立选择的设计维度。

小历史

2017 年原版 Transformer 是 Post-LN：x = Norm(x + f(x)) —— 归一化压在主干上，训练很挑，必须小心 warmup。
GPT-2 之后大家都改成 Pre-LN：x = x + f(Norm(x)) —— 归一化挪进支路，主干保持干净，那条「1」的直通电梯完全不被打扰。现在的 LLM 基本都是这个写法。

6

把残差流理解成一块公用白板

可以把 residual stream 想成一块从第一层传到最后一层的白板：每层读取当前内容，写入一个增量，再传给下一层。

图里每个「第 N 层」方块，里面都是 Attention + FFN 两个子层（第 4 节）—— 也就是读两次、写两次白板。这里画成一个方块只是为了看清白板本身。

为什么这个视角有用

浅层信息可以沿主干直接传到深层，不需要中间每层都重新编码一遍。

可解释性也靠它

研究者把残差流当模型的工作内存：某一层往里写了什么向量、后面哪一层读走了它，是可以逐层量出来的。这是「电路分析」类工作的基础。

7

残差需要归一化和合适的初始化

逐层累加会改变数值尺度，因此现代架构通常会把残差连接和归一化、合适的初始化一起使用。

① 归一化

每次读白板之前先 RMSNorm / LayerNorm 缩回合适量级，再交给子层算。只归一化副本，不动主干。

② 收尾再归一化

出模型前有一个 final norm，把攒了几十层的白板整理一次，才交给输出层。

③ 开局让 f(x)≈0

初始化时把子层最后一层权重压得很小，整个网络开局近似「什么都不做」，从最稳的状态开始学。

显存上的一点代价

加号本身不增加参数，计算开销也很小。但反向传播需要主干上的 x，所以每个残差点的激活值要保留到反向使用，这会占用一部分训练显存。

8

代码上就差一个 x +

# 没有残差：每层重写主干（深了就训不动）
x = attn(norm(x))
x = ffn(norm(x))

# 有残差：现代 LLM block 的基本结构
x = x + attn(norm(x))   # ← 加号在这
x = x + ffn(norm(x))    # ← 加号在这

这两个加号为梯度提供了直接路径，使 100+ 层网络更容易训练。

名词对照

下面这些名称都和残差连接有关，但强调的对象略有不同。

你会看到的词意思
残差连接 / Residual connection本页主角。out = x + f(x)
Skip connection / Shortcut同一个东西的别名，强调「有条路绕过了子层」
恒等映射 / Identity mapping指那条什么都不做的主干路径本身
残差流 / Residual stream把整条主干看成一块贯穿全模型的白板（第 6 节）
残差块 / Residual block「子层 + 一个加号」打包成的最小单元
子层 / Sub-layer被一个残差包住的那个算子本身。Transformer 里就两种：Attention 和 FFN
层 / Layer / Block口语里的「一层」= 两个子层 + 两个加号。GPT-3 的 96 层 = 192 个加号（第 4 节）
Pre-LN / Post-LN归一化放在支路里（现代）还是压在主干上（2017 原版）
ResNet2015 年系统展示残差连接效果的图像模型，扩展到 152 层。Transformer 延续了这种结构
Highway network更早的近亲，用一个「闸门」控制放多少原话过去。残差是它的极简版：闸门恒开
梯度消失 / 爆炸深层网络中，反传信号连续相乘后变得过小或过大（第 2 节）
每一层都读取同一条残差流，
再把自己的增量写回去。

前向时，主干保留已有信息；
反向时，恒等路径让梯度可以直接向前传播。

这个加号不增加可训练参数，计算开销很小，
因此几乎所有 Transformer 都会使用残差连接。
