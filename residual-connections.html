残差连接 · RESIDUAL

别重写，
只贴便签

深网络原来是「传话游戏」，传到第 90 层，原话早没了。
残差连接做的事，只有一件：把原话留着。

没有残差 原话 x → 这一层 → 全新的话，原话没了
有残差 原话 x → 这一层 → 原话 + 便签
out = x + f(x)

全部数学就这么多。一个加号。没有参数，没有算力开销。

1

问题：传话游戏

神经网络是一层传给下一层。层数一多，每层都想「改写」上一层的话，改到最后就是耳语传话——面目全非。

没有残差：每层重写

输入小明昨天在北京买了一辆红色的车
↓ 第 1 层重写
小明昨天在北京买了红车
↓ 第 2 层重写
小明买了红车
↓ 第 3 层重写
有人买了车
↓ 第 4 层重写
买东西
↓ 第 5 层重写
……？
原话已经找不回来了

有残差：原话不动，只加便签

小明昨天在北京买了一辆红色的车
↑ 这一行从头到尾都在
层1 +「小明」是人名
层2 +「北京」是地点
层3 +「红色」修饰的是车
层4 +「买」= 交易动作，过去时
层5 +整句是陈述、已完成
最后读到的 = 原话 + 全部便签
这不是「跳过某一层」

常见误解。每一层照样算，只是它的输出被 加 回主干，而不是 替换 主干。
层的职责从「产出新的一切」降级成「产出一点增量」——这就是名字里「残差 / residual」的意思：差值。

前 3 节的「层」请先当成一个黑盒 —— 它可以是卷积、可以是 attention、可以是任何东西，残差不在乎。第 4 节把盒子打开。

2

真正致命的是反向：信号被乘到 0

训练要从最后一层往回传「你该往哪改」的信号。每穿过一层，这个信号就被乘一个数。乘 90 次，猜猜剩多少。

96
没有残差 —
有残差 100%

没有残差

0.8 × 0.8 × 0.8 × … （96 次）

= 0.00000005%
信号到不了底层。底层的参数几乎不更新，等于白搭了 90 层。这叫梯度消失。

乘数稍大于 1 也一样糟：1.196 ≈ 8600，直接炸成 NaN

有残差

d(x + f(x)) / dx = 1 + f′(x)

那个 1 是一条直通电梯：
1 × 1 × 1 × … = 1
不管多少层，永远有一条不衰减的路把信号送到底。

这才是「能训 100 层」的原因
3

顺带解决：加层不该让模型变差

2015 年发现一件反常识的事：56 层的网络，训练误差比 20 层的还高。不是过拟合——它连训练集都学不好。深度本身成了负担。

要一层「什么都别做」

没有残差：它得学会照抄——把输入一字不差地复现出来。看着简单，对一堆随机初始化的矩阵来说非常难。

类比：让编辑「原文抄一遍，不许出错」

有残差：只要不写字

out = x + f(x)，想不做事只需 f(x) → 0。把权重压到 0 是优化器最容易做到的事之一。

类比：让编辑「这页不用改，空着」
于是深网络最差也能退化成浅网络

多出来的层用不上就自己「空着」。加层从此只有上限收益、没有下限风险。
ResNet 靠这一招，把图像网络从 20 层推到 152 层。同一招原封不动搬进了 Transformer。

4

插播：残差 ≠ Attention

最容易混的一件事。这两个词根本不在同一个层面上——一个是管道，一个是水。

残差连接 = 管道怎么接

规定「子层算完的东西怎么并回主干」：加，而不是替换。
它不关心子层里算的是什么。

0 个参数

Attention = 管道里跑什么水

一种具体算子，负责「这个词该去看句子里的哪些词」。
它不关心自己是怎么被接进去的。

一大堆参数
而且「一层」里不止一个东西

口语里的「一层」= 一个 Transformer block = 两个子层，两个残差加号：

x = x + Attention(norm(x))   ← 子层 1：去别人那儿看看
x = x + FFN(norm(x))         ← 子层 2：自己再想想

所以 GPT-3 的「96 层」= 96 个 block = 192 个残差加号。
Attention 只是这两个子层里的一半。

Attention 子层

干什么跨 token 看别人
看得到别的词吗能 —— 而且是全模型唯一能让词之间通信的地方
白板比喻抄一眼旁边人的白板，再写便签
参数量约 1/3（4d²）

FFN 子层

干什么每个 token 自己想
看得到别的词吗看不到 —— 逐位置独立处理，互不通气
白板比喻只看自己白板，加工一下再写便签
参数量约 2/3（8d²）

顺带一提，Norm 也是逐 token 的（它在特征维度上归一化，不跨词）。所以信息在句子里流动，全靠 attention 那一个子层。

一句话验证它们真的无关

把 attention 换成卷积（ResNet）、换成 SSM（Mamba），残差原封不动照旧。
Mamba 里一个 attention 都没有，但残差一个不少。

反过来，把残差拆掉，attention 照样能算 —— 只是网络一深就训不动了（第 2 节）。
两者可以任意组合，说明它们是正交的两件事。

小历史

2017 年原版 Transformer 是 Post-LN：x = Norm(x + f(x)) —— 归一化压在主干上，训练很挑，必须小心 warmup。
GPT-2 之后大家都改成 Pre-LN：x = x + f(Norm(x)) —— 归一化挪进支路，主干保持干净，那条「1」的直通电梯完全不被打扰。现在的 LLM 基本都是这个写法。

6

换个视角：它其实是一块公用白板

「残差流（residual stream）」这个叫法更传神。别把它想成「捷径」，想成一块从第一层传到最后一层的白板：每层过来看一眼，写点东西，传给下一层。

图里每个「第 N 层」方块，里面都是 Attention + FFN 两个子层（第 4 节）—— 也就是读两次、写两次白板。这里画成一个方块只是为了看清白板本身。

为什么这个视角有用

因为它解释了为什么浅层的信息能直接被深层用到——白板上一直在。不需要中间每层都「转述」一遍。

可解释性也靠它

研究者把残差流当模型的工作内存：某一层往里写了什么向量、后面哪一层读走了它，是可以逐层量出来的。这是「电路分析」类工作的基础。

7

代价：白板会越写越挤

一直往上加，数值就一直变大。所以残差从来不单独出现，总带着两个配套。

① 归一化

每次读白板之前先 RMSNorm / LayerNorm 缩回合适量级，再交给子层算。只归一化副本，不动主干。

② 收尾再归一化

出模型前有一个 final norm，把攒了几十层的白板整理一次，才交给输出层。

③ 开局让 f(x)≈0

初始化时把子层最后一层权重压得很小，整个网络开局近似「什么都不做」，从最稳的状态开始学。

显存上的一点代价

加号本身不要参数、不要算力。但反向传播需要主干上的 x，所以每个残差点的激活值得留着。这就是训练比推理吃显存的原因之一——不是残差的锅，但残差点是这些激活的落脚处。

代码上就差一个 x +

# 没有残差：每层重写主干（深了就训不动）
x = attn(norm(x))
x = ffn(norm(x))

# 有残差：现代 LLM 每个 block 的全部内容
x = x + attn(norm(x))   # ← 加号在这
x = x + ffn(norm(x))    # ← 加号在这

两个字符。深度学习能从 20 层做到 100+ 层，一半功劳在这两个字符上。

9

名词对照

同一件事有很多叫法，看到别慌，都是那个加号。

你会看到的词意思
残差连接 / Residual connection本页主角。out = x + f(x)
Skip connection / Shortcut同一个东西的别名，强调「有条路绕过了子层」
恒等映射 / Identity mapping指那条什么都不做的主干路径本身
残差流 / Residual stream把整条主干看成一块贯穿全模型的白板（第 6 节）
残差块 / Residual block「子层 + 一个加号」打包成的最小单元
子层 / Sub-layer被一个残差包住的那个算子本身。Transformer 里就两种：Attention 和 FFN
层 / Layer / Block口语里的「一层」= 两个子层 + 两个加号。GPT-3 的 96 层 = 192 个加号（第 4 节）
Pre-LN / Post-LN归一化放在支路里（现代）还是压在主干上（2017 原版）
ResNet2015 年把这招做火的图像模型，152 层。Transformer 直接继承
Highway network更早的近亲，用一个「闸门」控制放多少原话过去。残差是它的极简版：闸门恒开
梯度消失 / 爆炸残差要治的病：反传信号被连乘成 0 或炸上天（第 2 节）
层不是流水线上的工人，
是围着同一块白板贴便签的人。

加号让「原话」永远不丢 —— 这是前向。
加号让「该怎么改」的信号永远不消失 —— 这是反向。

一个不占参数、不占算力的加号，同时解决了这两件事。
所以它出现在你见过的每一个 Transformer 里，一个都没落下。
