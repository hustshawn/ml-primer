先认基础概念

这一组都是后面会反复再碰到的东西，而它们本身不依赖后面任何一页 —— 所以放最前面。不先弄明白，看 attention 和训练都会卡。

非线性 / Nonlinearity可交互 · 4 个实验台

线性只会按比例
非线性会看情况

不讲「它让网络能学复杂东西」，只讲为什么。线性的全部本事是给每样东西打一个固定的分再相加 —— 于是叠一百层等于一层、永远只能一刀切、不会「看情况」。四个实验台：阶梯电费单上的那个折点、方格纸怎么被折出折痕、两把刀为什么会自动合并成一把、折 n 次纸为什么等于 2ⁿ 段直线。
Softmax可交互 · 温度滑块

一堆乱数
→ 一组概率

套个 e，再各自除以总和 —— 整个 softmax 就这三步。temperature 就是进 softmax 之前先除以 T，它只改变第一名领先多少，不改变谁是第一名。
Residual可交互 · 深度滑块

别重写，
只贴便签

深网络原来是「传话游戏」，传到第 90 层原话早没了。残差连接做的事只有一件：把原话留着。代码上就差一个加号。
RMSNorm可交互 · 缩放滑块

扔掉长度
留下方向

深网络每层都在乘，走过上百层数字要么炸成天文数字要么缩成 0。归一化就是每层门口把音量调回标准值 —— 除以 RMS，上一层输出多响，下一层完全感觉不到。比 LayerNorm 少做了「减均值」那一步，参数量从 2d 降到 d，而每个 block 要用 2 次。
激活值 / Activation可交互 · 显存计算器

权重是石头
激活值是水

前向路上每一层算出来的中间结果就是激活值 —— 它不在 checkpoint 里，却常是训练时最占显存的一块。四块显存里只有它随 batch × 序列长度长。把一层摊开数出 18 个张量，顺带解掉 activation checkpointing、FlashAttention、KV cache、W8A8 里的那个 A。

再看架构

Transformer 是怎么被想出来的，它最核心的那个零件到底在算什么，以及为什么后来所有人都只用了它的一半。大致按「论文 → 零件 → 架构选择」的顺序读。

2017 · 论文

Attention Is
All You Need

它做的事一句话说完：把「一个词一个词地读」这件事彻底扔掉。公式只有四步，一层只有四个盒子，成绩还更好、更便宜。
Attention / Head可交互 · 热力图

Attention 是什么
Head 又是什么

attention = 一次由内容决定的加权平均（权重当场算，不是训好固定的）；head = 同一件事并行做 8 遍，各用一套标准。顺带讲清 MHA / GQA / MQA 改的是哪个轴。
MLP / FFN可交互 · 神经元滑块

开完会，
各自消化

block 里被冷落的另一半：attention 负责词与词之间搬信息，MLP 负责每个词独立深加工 —— 摊开、掰弯、压回。一层 block 里 2/3 的参数是它，事实性知识大多也存在它里面；MoE 的「专家」就是一堆 MLP。
Decoder-only可交互 · mask 实验台

三种架构
为什么只剩一种

encoder-only / encoder-decoder / decoder-only 的全部差别，只是一张 attention mask —— 允不允许往后看。往后看一眼就能作弊，所以必须涂掉答案，所以一遍前向只出得了 15% 的题，所以缓存也存不住。下三角形一刀切掉「未来」，这一串问题全部消失。附一节诚实的反例：换成多任务微调，赢的就不是它了。
条件记忆 / Engram可交互 · 哈希 / 闸门 / 配比滑块

有些事该查，
不该算

模型里唯一的「查表」动作是 input embedding，而它的钥匙只有一个 token —— 所以「Alexander the Great 是个人名」这种纯粹该背的东西，它只能用 6 层硬算出来。这一页讲把那个动作放大：钥匙从一个 token 扩成一个短语，位置从第 0 层挪到中间层。组合数比格子数多 8 个数量级，于是碰撞、闸门、装第几层依次登场。收尾是两件反直觉的事：推理题比知识题涨得更多，以及纯靠算力是次优的。

然后是训练

给已经懂推理的人补上训练侧。顺序大致是从小往大：先掰开最基本的计数单位，再看训练一圈是怎么转的、那些名词分别落在模型的哪一段人生里，最后是最常用的微调方法。

Epoch / Step / Batch可交互 · batch size 切换

训练就是
刷一本习题册

一道题 = 一条样本，一叠题 = 一个 batch，做完一叠改一次参数 = 一个 step，整本刷完一遍 = 一个 epoch。带一个能跑的 100 题动画：调 batch size 看 step 数怎么变，以及为什么日志横轴上的 global step 跨 epoch 不归零。
训练机制

训练 = 推理
+ 两步

你熟悉的前向传播就是训练的第一步，剩下要补的只有「算错多少」和「怎么改」。附显存账本（训练 ≈ 推理的 8 倍）、四种并行切法、LoRA、算力估算。

一个模型的
四段人生

读书 → 学做事 → 学做人 → 学思考。四段的区别只在于谁在打分。你听过的所有名词都落在这四格里 —— 包括几个常被叫做「训练」其实不是的。
Post-training可交互 · 5 个实验台

后训练那一堆方法
只差谁在打分

SFT / RLHF / PPO / DPO / 拒绝采样 / GRPO / 蒸馏 —— 名词一大把，三个问题就能全部归位：一条样本长什么样、谁打分、答案是谁生成的。五个实验台：loss 挡在哪些 token 上、奖励模型为什么只有差值有意义、KL 拴绳一松就开始胡言乱语、best-of-N 的 N 开大反而挑到骗分的那条、GRPO 一组全对或全错为什么白跑。收尾是 InstructGPT / Llama 3 / DeepSeek-R1 三条真实流水线。
LoRA / QLoRA可交互 · rank 滑块

底模一个字不改
只训旁边那块补丁

LoRA 不是一个训练阶段，是「哪些参数有梯度」这一层的选择。机理只有一个加号；省的是优化器状态，不是 activation；推理要么 merge 掉换零开销，要么留旁路换热切换。

最后是多卡

这一组是系统层，不是模型层 —— 一张卡装不下、算不完的时候，卡怎么分工、卡之间怎么说话、这活儿到底要几张卡。它不只属于训练：张量并行推理时照样每层通信。顺序是「怎么切 → 怎么通信 → 怎么估」。

数据并行 / DP可交互 · 卡数滑块

模型复制 N 份
数据切成 N 份

名字里的「数据」就是被切开的那个东西 —— 复制的从来是模型。一步只有一个同步点（all-reduce 平均梯度），DP 一个字节显存都不省；推理侧没有梯度，它就退化成多副本 + 负载均衡。
集合通信 / Collectives可交互 · 8 个动作实验台

八个名字
其实是拼出来的

broadcast / scatter / gather / reduce / all-gather / reduce-scatter / all-to-all —— 四个词根加一个 All- 前缀（结果人人有一份），拼一下就知道它在搬什么。all-reduce 是全家唯一走两趟的（= reduce-scatter + all-gather），所以每卡通信量是别人的 2 倍；all-to-all 根本不做算术，它是把 4×4 的表转置 —— MoE 的 token 路由靠它。含 ring 分步演示：为什么加卡不加通信量。
资源估算 / Sizing可交互 · 显存 / 工期估算器

「要几张卡？」
这问题没法直接答

它不是一个问题，是显存 / 算力 / 互联三个约束的交集：显存定下限，算力定工期，互联决定能怎么切。两个联动的估算器 —— 拨模型和 ZeRO stage 看每卡显存分解与卡数下限，拨 token 量和 MFU 反算工期。重点是先搞清该问什么，再算。
