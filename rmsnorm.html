02 · RMS 是什么

三步算出
“平均有多大”

一层的输出是一串数字。比如这四个 👇

[ −3,  4,  0,  5 ]
①

全部平方

9, 16, 0, 25

负号消失了，只剩“多大”

②

求平均

50 ÷ 4 = 12.5

Mean

③

开根号

√12.5 = 3.54

Root — 这就是 RMS

↓ 每个数都除以 3.54
RMSNORM 的输出
[ −0.85,  1.13,  0,  1.41 ]

Root Mean Square 三个词，就是倒着念这三步：开根号、求平均、平方。

04 · 换个看法

扔掉长度
留下方向

把一串数字当成一支箭。除以 RMS，就是把所有箭拉到同一个圈上。

信息全在“指哪儿”，不在“多长”。

05 · 和 LayerNorm 的区别

少做了一步

LayerNorm（老办法）

  • ①算均值，每个数减掉它 → 重心挪到 0
  • ②算标准差，每个数除掉它 → 缩放
  • ③可学习的 g 和 b（缩放 + 偏移）

参数量：2d

现在的主流

RMSNorm

  • ①减均值 —— 不做了
  • ②除以 RMS → 缩放
  • ③可学习的 g（只有缩放）

参数量：d

2019 年的 RMSNorm 论文发现：减均值那一步基本没贡献，让训练稳下来的是缩放。

于是把它删了。少一遍数据、少一组参数、少一次减法。效果基本不变。

06 · 那个小旋钮

压平之后
再给模型调音台

归一化把所有维度按同一把尺子压平了。但有些维度本该更响。
所以每个维度配一个可学习的增益 g——模型自己训出来的调音台。

推子的位置不是人调的，是训练学出来的。

07 · 为什么在 LLM 里这么重要

四个理由

🧱

不炸

几十上百层堆起来还能训下去。这是能不能开始训的前提。

🚀

敢用大学习率

数值稳了，学习率就能开大，收敛更快，省出来的是真金白银的 GPU 小时。

🪶

够便宜

只需要平方和：不用算均值、不用减、没有 bias。

🔁

用得极多

每个 Transformer block 用 2 次，乘上上百层。省一点点，乘几百次。

顺便说：现代 LLM 把它放在每个子层之前（pre-norm），让残差主路保持一条干净的直通道——这也是深层能训起来的关键之一。

09 · 全部内容

五行写完

# x: [..., d]   g: [d] 可学习
def rmsnorm(x, g, eps=1e-6):
    ms  = x.pow(2).mean(-1, keepdim=True)   # ② 平方求平均
    return x / (ms + eps).sqrt() * g          # ③ 开根号，除掉，再乘旋钮

eps 是防止全零向量除以 0 的小保险。

一句话：
扔掉长度，留下方向，
再给模型一个旋钮调回来。
